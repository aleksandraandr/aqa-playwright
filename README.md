## ✅ Task 1: REGISTER — demo-login-form

### 📄 Description

Разработайте смоук тест-сьют с тестами на REGISTER на странице:  
https://anatoly-karpovich.github.io/demo-login-form/

#### Requirements:
- **Username**
  - Required field
  - From 3 to 40 characters (inclusive)
  - Leading and trailing spaces are not allowed
  - Username consisting only of spaces is not allowed
- **Password**
  - Required field
  - From 8 to 20 characters (inclusive)

  //     return "Password should contain at least one character in upper case"
  // }
The test Password without uppercase is intentionally left and marked as [KNOWN ISSUE]

  Требования:
  Email: обязательное, уникальный
  Name: обязательное, Customer's name should contain only 1-40 alphabetical characters and one space between
  Country: обязательное, ['USA', 'Canada', 'Belarus', 'Ukraine', 'Germany', 'France', 'Great Britain', 'Russia']
  City: обязательное, City's name should contain only 1-20 alphabetical characters and one space between
  Street: обязательное, Street should contain only 1-40 alphanumerical characters and one space between
